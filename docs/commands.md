# Commands

Everything in Felbound can be set in the options window (`/fel`). These chat commands are shortcuts.

`/felbound` works everywhere `/fel` does. On a character that isn't a warlock, the commands only say that Felbound does nothing there.

## Windows

| Command | What it does |
| --- | --- |
| `/fel` | Opens or closes the options window. `/fel options` and `/fel config` do the same. |
| `/fel help` | Lists every command in chat. |

## Frames

| Command | What it does |
| --- | --- |
| `/fel unlock` | Unlocks all frames so you can drag and resize them. See [Layout](features/layout.html). |
| `/fel lock` | Locks the frames again. |
| `/fel move` | Unlocks the frames, or locks them if they are unlocked. |
| `/fel reset` | Puts every frame back in its default place and size. |
| `/fel grid` | Turns snapping to the grid on or off. |
| `/fel grid 30` | Sets the grid size (4 to 100) and turns snapping on. |
| `/fel minimap` | Shows or hides the minimap button. |

## Tooltips

| Command | What it does |
| --- | --- |
| `/fel explain` | Turns the [explanations in tooltips](features/explanations.html) on or off. |

## Without a space

Every command also works without the space, for example `/felunlock`, `/felreset` or `/felhelp`. Use these if your chat setup swallows the Enter key after a space.

Type anything else after `/fel` to get the list of commands in chat.

The [buff key](features/buff-key.html) is not a command: set it on the **Extras** page of `/fel`.
