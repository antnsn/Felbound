# Soul Shards

Soul Shards pay for your demons (all but the Imp), Healthstones and Soulstones. You get one with Drain Soul on an enemy as it dies. Felbound tells you when you are running low.

## What it does

- A card titled **Soul Shards** appears when you have 3 shards or fewer (you can change this). It says how many are left, for example "2 left", or **None left** in red.
- It only shows once you know Summon Voidwalker. Before that, you have nothing to spend shards on.
- It stays hidden in combat.
- This card is a reminder only: clicking it does nothing. Get shards with Drain Soul.

## How to use it

1. Type `/fel` and open the **Stones & shards** page.
2. Check that **Warn when Soul Shards run low** is ticked.
3. Set **Shards: warn at** to the number of shards you want to keep.

## Settings

In `/fel`, page **Stones & shards**:

| Setting | Default | What it does |
| --- | --- | --- |
| Warn when Soul Shards run low | On | Shows the card. |
| Shards: warn at | 3 left | The card shows at this many shards or fewer. 0 to 20. At 0, it only shows when you have none. |

## Good to know

**I have exactly 3 shards and the card is up.**
The card shows at the number you set, not only below it. Set it to 2 if you want it to wait until you have 2.

**Where do my shards go?**
Summoning the Voidwalker, Succubus or Felhunter, and making a Healthstone or Soulstone, each use one. The [demon card](demon.html) and the [stone card](healthstone-and-soulstone.html) both tell you when they need a shard you don't have.
